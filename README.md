# PAC-Scripts
Just some PAC Scripts for testing proxies on a Chromebook. 

# How to add
Go to Network on your settings page and navigate to the internet you want to apply the proxy to. Then scroll to the bottom and open the folder proxy. Change the connection type to **Autoconfiguration URL** and then paste the **raw** github url into the text box below. Which usually looks something like: "https://gist.githubusercontent.com/*your-username*/*random-string*/gistfile1.pac". 
**Note**: All given proxy urls inside of the files are only placeholders and **will not work**. **Do not** create a issue telling me that they are broken.
